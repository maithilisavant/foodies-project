# foodies-project

# Next.js MongoDB App

This project is a Next.js application that uses MongoDB as the backend database and Jest for testing. The application provides a robust framework for building scalable web applications with a focus on performance and developer experience.

## Features

- Server-side rendering and static site generation
- CRUD operations with MongoDB
- Responsive design
- Comprehensive test coverage with Jest

- ## Technologies Used

- **Next.js**: A React framework for building server-rendered applications.
- **MongoDB**: A NoSQL database for storing application data.
- **Jest**: A testing framework for JavaScript.

- ## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (v14 or later)
- npm or yarn
- MongoDB (local or cloud instance)

### Installation

1. Clone the repository:
   git clone git@github.com:maithilisavant/foodies-project.git
   cd foodies-project


2. Install the dependencies
   
   npm install
    # or
   yarn install

   
3. Setting Up MongoDB
    Create a MongoDB database (locally or on MongoDB Atlas).
    Update the connection string in your environment variables.


4. Folder Structure
   /root
  ├── /components        # React components
  ├── /pages             # Next.js pages
  ├── /styles            # CSS styles
  ├── /utils             # Utility functions
  ├── /tests             # Jest test files
  └── /api               # API routes for backend logic


5. Running the Application
   npm run dev
     # or
   yarn dev

6. Running Tests
    npm test
      # or
    yarn test
